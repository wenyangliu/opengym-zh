# openGym 中文动作库

健身动作数据库，**5632 个动作**，字段名英文、内容全中文。供 AI 大模型 / 应用直接读取。

数据取自 [openGym](https://github.com/DuarteSantos8/openGym) 的 `catalogue/exercises`，翻译为中文后重新整理。

## 文件结构

| 文件 | 大小 | 说明 |
|:---|---:|:---|
| `full.json` | 2.8 MB | 全部 5632 条，含分步说明 |
| `index.json` | 1.3 MB | 精简版，去掉 `instructions`，只留描述 |
| `parts/part_*.json` | 30–780 KB | 按身体部位拆分（11 个） |
| `chunks/chunk_01..29.json` | 约 96 KB | 每 200 条一块，**推荐 AI 读取用** |

## 怎么给 AI 用

大模型上下文装不下 2.8 MB，别直接喂 `full.json`。按用途选：

- **只想知道有哪些动作** → `index.json`，或读 `chunks/` 里对应的一块
- **要某个部位的全部动作** → `parts/part_chest.json`（约 246 KB）
- **要单个动作的完整步骤** → 先从 `index.json` 按 `id` 定位，再取 `full.json` 里同 `id` 的条目

`chunks/` 每块 200 条、约 96 KB，是最适合单次读取的粒度。
